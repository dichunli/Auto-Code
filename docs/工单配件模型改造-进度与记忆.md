## 一、术语与目标模型（三层）

```
维修项目
  └─ 配件名称（叶子目录，可有多个同名但相互独立的目录）
       └─ 配件（分支，可多个；其中一条为“默认/选中”）
```

关键规则（已与用户确认）：
- **可以存在多个同名但相互独立的叶子目录**。
- **数量属于“叶子目录”层级**：一个目录一个数量，组内所有分支共用、保持同步。
- 一个目录下**只能有一条分支被选中（默认）**。
- **目录金额 = 目录数量 × 被选中分支的销售价(unit_price)**。
- **配件提成：只算被选中（默认）分支**，未选中的备选分支不算。
- 配件名称统一不变；**供应商单据上的不同名称记到“单据名称”(`document_name`)**。
- **移动端要有“删除整个配件名称分组（目录及其所有分支）”的入口**（对齐桌面端组头的“删除该配件及其所有分支”）；现有“删除”只删当前单条分支。
- **移动端配件行要显示“选中分支的品牌”+ 价格**，让客户看到“选这个品牌的配件 → 价格多少”（已部分实现：行已显示选中分支 品牌·规格 + 金额，品牌为空时不显示）。

### 阶段0 迁移 SQL（核心）
```sql
ALTER TABLE work_order_item_parts ADD COLUMN IF NOT EXISTS branch_group_id UUID;
-- 同一(item, part_name_id)归一个目录
UPDATE work_order_item_parts t SET branch_group_id = m.gid
FROM (SELECT work_order_item_id, part_name_id, gen_random_uuid() gid
      FROM work_order_item_parts WHERE part_name_id IS NOT NULL
      GROUP BY work_order_item_id, part_name_id) m
WHERE t.work_order_item_id=m.work_order_item_id AND t.part_name_id=m.part_name_id AND t.part_name_id IS NOT NULL;
-- 无配件名称的每行各自一个目录
UPDATE work_order_item_parts SET branch_group_id = gen_random_uuid() WHERE branch_group_id IS NULL;
CREATE INDEX IF NOT EXISTS idx_woip_branch_group ON work_order_item_parts(branch_group_id);
```
