# 微信群配件需求采集小工具 - 使用说明

> 这份说明写给**不懂电脑技术的同事**，照着一步一步做即可。全程大约 30 分钟。
> 遇到问题先翻最后的【常见问题】，解决不了就把屏幕截图发给技术人员。

## 这个工具是干什么的

车间同事在微信群里面发"哪台车需要什么配件"（拍车牌照片 + 打字说配件名）。
这个工具会自动盯着群消息，把消息整理成一个**网页看板**：

- 同一个同事连续发的消息（照片+文字）自动归成一组
- 文字里出现的车牌号自动标出来
- 处理完一条打个勾，浏览器会记住

看板是一个网页文件，**双击就能打开看**，不用装任何东西。

## 第一步：准备一台电脑

- 找一台**白天一直开着**的电脑（前台收银那台就行）
- 这台电脑上要装 **PC 版微信**，登录一个**专门的小号**，把小号拉进目标群
- ⚠️ 不要用任何人日常在用的微信号，就用小号
- ⚠️ 登录后把微信的自动升级关掉：微信左下角「≡」→ 设置 → 通用设置 → 取消勾选「有更新时自动升级微信」

## 第二步：安装 Python（一次性）

1. 打开网址 https://www.python.org/downloads/ ，点黄色大按钮下载
2. 双击下载好的安装包
3. ⚠️ **安装第一屏最下面有个「Add python.exe to PATH」的勾，一定要勾上**，再点「Install Now」
4. 装完点 Close

## 第三步：把本文件夹复制到那台电脑

把整个 `wechat-poller` 文件夹拷到那台电脑（比如放到桌面）。

## 第四步：安装依赖（一次性）

1. 打开 `wechat-poller` 文件夹，在地址栏输入 `cmd` 回车（会打开一个黑色命令行窗口）
2. 输入下面这行，回车，等它跑完（要联网）：
   ```
   pip install -r requirements.txt
   ```

## 第五步：填写群名

用记事本打开 `config.ini`，把 `groups =` 后面改成目标群的**群名**（和微信里显示的一字不差），保存。

## 第六步：验证（重要，别跳过）

1. 确认那台电脑上的微信**已经登录小号**
2. 在命令行窗口输入：
   ```
   python poller.py --test
   ```
3. 它会分 5 步打印检查过程。看到最后「诊断完成」并且**能看到群里的消息内容**，就说明环境没问题
4. 如果卡在某一步，把它打印的中文提示照着做（比如群名不对、微信没登录），还不行就截图发给技术人员

## 第七步：正式运行

**双击文件夹里的 `启动采集.bat`** 即可（后台最小化运行）。

也可以在命令行窗口输入 `python poller.py`（这样能看到运行日志）：

- 窗口里会打印「已启动」，然后每隔 30 秒检查一次新消息
- **命令行窗口不能关**，关了采集就停了（用 bat 启动则看不到窗口，要停就到任务管理器结束 python 进程）
- 生成的看板在 `输出` 文件夹里，文件名是 **配件需求看板.html**，双击打开
- 每次想看最新消息，把看板网页**刷新一下**（按 F5）就行
- 文件夹里的 `看板效果预览.png` 是看板长什么样的示例图

## 每天怎么用（给采购员）

1. 早上打开 `输出` 文件夹里的「配件需求看板.html」
2. 从上往下看，每条需求：看照片里的车牌、看文字里的配件名
3. 处理完一条，勾选右下角的「已处理」，备注里写一句（如"已下单"）
4. 已处理的会变淡，沉到视野之外；没处理的始终醒目

## 设置开机自动启动（可选，建议做）

免得每天手动开：

1. 按 `Win + R`，输入 `shell:startup` 回车
2. 把文件夹里现成的 `启动采集.bat` 复制一份快捷方式放进去
3. 以后电脑开机登录后会自动开始采集（注意微信也要设置开机自启并自动登录）

## 常见问题

| 现象 | 原因和解决办法 |
|------|---------------|
| 提示"没有安装 PyWxDump" | 第四步没做或没联网，重新跑 `pip install -r requirements.txt` |
| 提示"读取微信信息失败" | 微信没登录。登录小号后重试 |
| 诊断时"没找到群" | ①小号没被拉进群 ②config.ini 群名和微信里不一致（多空格都不行） |
| 密钥为空 / 解密失败 | 微信版本太新，工具还没适配。**不要升级微信**；截图发技术人员 |
| 看板里图片显示"读取失败" | 个别图片解密不了属正常，点不开的图去微信群里看原图 |
| 微信突然升级了，工具不好使 | 等 PyWxDump 出新版；或让技术人员把微信装回旧版本 |
| 脚本自己停了 | 看黑窗口里的红字，大多重跑一次 `python poller.py` 就好；反复不行截图发技术人员 |
| 换了微信号登录 | 重新跑一遍第六步的验证 |

## 两个纪律（很重要）

1. **微信不要升级**：升级后工具可能读不出消息。看到微信提示升级，点取消
2. **小号专用**：这个微信号只用来进群收消息，不要在别的手机/电脑上登录它，否则会顶掉采集电脑上的登录
